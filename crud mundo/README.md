# CRUD Mundo
## Sobre o projeto
O projeto consiste em uma aplicação focada no gerenciamento de dados geográficos como continentes, países, estados ,cidades, seus respectivos governantes e informações.
## Funcionalidades
- Cadastramento de continentes, países, estados ,cidades, seus respectivos governantes e informações.
- Edição de continentes, países, estados ,cidades, seus respectivos governantes e informações.
- Exclusão de continentes, países, estados ,cidades, seus respectivos governantes e informações.
- Visualização de continentes, países, estados ,cidades, seus respectivos governantes e informações.
- Cadastro e autenticação de usuário.
- Manutenção de senha do usuário.
## Tecnologias utilizadas
- HTML
- CSS
- PHP
- MySQL
## Como executar
### Tecnologias necessárias
- XAMPP (servidor local)
- Navegador (Chrome, Firefox, Opera, Brave ou semelhante)
### Etapas
1. Iniciar o XAMPP e ativar o MySQL e o Apache
2. Executar o arquivo .sql (pode ser no MySQL Workbench ou no http://localhost/phpmyadmin)
3. Clonar o repositório (dê preferência a escolher a pasta htdocs do xampp, caso contrário terá que copiar o projeto para o mesmo)
4. Abrir o navegador
5. Digitar o endereço do servidor local (Para acessar o servidor local do XAMPP no navegador, digite http://localhost ou http://127.0.0.1 na barra de endereços.)
6. Selecionar a pasta CRUD Mundo no repositório PWIII
